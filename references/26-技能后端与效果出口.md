## 1. 三张核心表关键字段

`unit_abilities_tables`（12 列）关键列：`key` `requires_effect_enabling` `icon_name` `overpower_option` `type` `uniqueness` `is_unit_upgrade` `is_hidden_in_ui` `source_type` `superseded_abilities_set` `is_hidden_in_ui_for_enemy`

- `icon_name` 无扩展名，引擎到 `ui\battle ui\ability_icons\<icon_name>.png` 取图；`overpower_option`：基础版填超载版 key，超载版留空。
- `type` → `unit_ability_types_tables`（30 条，只决定 UI 分类与光标）；`source_type` → `unit_ability_source_types_tables`（23 条）。

`unit_special_abilities_tables`（74 列）关键列：

- 时间/次数：`active_time`（-1=不占用）、`recharge_time`、`num_uses`（-1=无限）、`initial_recharge`、`shared_recharge_time`
- 范围/目标：`effect_range`（0=自身/-1=全图）、`target_intercept_range`、`min_range`、`target_self`/`target_friends`/`target_enemies`/`target_ground`、`affect_self`/`only_affect_target`/`only_affect_owned_units`、`num_effected_friendly_units`/`num_effected_enemy_units`、`update_targets_every_frame`
- 出口/表现：`activated_projectile`、`bombardment`、`vortex`、`spawned_unit`、`wind_up_time`、`wind_up_stance`、`wind_down_stance`、`special_ability_display`、`audio`
- 魔风/失误：`mana_cost`、`miscast_chance`、`miscast_explosion`、`miscast_global_bonus`
- AOE/AI：`targetting_aoe`、`passive_aoe`、`active_aoe`、`ai_usage`、`autoresolver_usage`（**不可空**）
- 其它：`passive`、`unique_id`、`formation`、`behaviour`、`intensity_based_activation`、`spawn_type`、`spawn_is_decoy`/`spawn_is_transformation`/`spawn_shares_health_and_fatigue`

`special_ability_phases_tables`（31 列）关键列：
`id` `duration` `effect_type` `cant_move` `fatigue_change_ratio` `ability_recharge_change` `hp_change_frequency` `damage_amount` `max_damaged_entities` `resurrect` `mana_regen_mod` `mana_max_depletion_mod` `imbue_magical` `imbue_ignition` `imbue_contact` `phase_display` `is_hidden_in_ui` `affects_allies` `affects_enemies` `replenish_ammo` `spreading` `heal_amount` `barrier_heal_amount` `remove_magical` `execute_ratio`（全列以表头为准）

- `duration=-1` 永久（被动）；`effect_type` = `positive`/`negative`/`neutral`；`fatigue_change_ratio` 负值恢复、正值加重。
- DoT：`hp_change_frequency`（秒）+ `damage_amount` + `max_damaged_entities`（**必须限制**）。

## 2. 攻击附魔（imbue_contact）完整链路

**前提**：WH3 原版**没有** `wh_main_effect_unit_enable_contact_poison` 这类通用 effect（旧词典里的都不存在）。接触效果只能自定义 passive + phase 的 `imbue_contact`。

```
① effects_tables                自定义 effect（如 wh_my_effect_enable_hellfire_attacks）
② effect_bonus_value_special_ability_phase_record_junctions_tables
                                bonus_value_id=active | effect | special_ability_phase=相位key
③ special_ability_phases_tables 相位本体：duration / effect_type=negative / imbue_contact=<接触类型key>
④ special_ability_phase_stat_effects_tables   phase | stat | value | how（add/mult）
⑤ 载体：ancillary_to_effects_tables（装备）或 bundles junction（战旗/科技/技能树）
⑥ loc：special_ability_phases_onscreen_name_<相位key>
```

- `imbue_contact` 填**接触类型 key**（原版合法值）：`wh_main_unit_contact_poison`、`wh_dlc06_unit_contact_blinded`、`wh_dlc06_unit_contact_discouraged`、`wh_dlc06_unit_contact_flammable`、`wh_dlc06_unit_contact_sundered_armour`、`wh_dlc06_unit_contact_shock`、`wh_main_unit_contact_morale`。
- 攻击附魔**不挂 `unit_special_ability`**（无冷却、不可点按），只靠 ② 的 `active` 行激活；`phase_display` 用原版 key，`is_hidden_in_ui=false` 让被命中者看到提示。
- 接触效果是 **phase，允许自定义**；`unit_attributes` 禁止新增——两者别混。`ignore_imbue_contact_effects_enemy`/`_ally` 可免疫敌方/忽略友方接触。

**验收**：`imbue_contact` 值在原版 phase 表中作为 key 存在；② 的 `bonus_value_id=active`；命中后图标与减益出现。

## 3. 被动光环 + 击杀成长（intensity）

```
① unit_special_abilities_tables   passive=true, effect_range=-1 或半径, affect_self=true
② special_ability_to_special_ability_phase_junctions_tables
                                  order=1 | ability | target_self=true | target_friends=true | target_enemies=false | phase
③ special_ability_phases_tables   effect_type=positive, affects_allies=true, affects_enemies=false, duration=-1
④ special_ability_phase_stat_effects_tables   自身/友军光环数值（add / mult）
⑤ special_ability_intensity_settings_tables   ability | default_amount | max_amount | intensity_source | intensity_type | decay_delay | decay_duration | reset_in_reinforcement
⑥ unit_abilities_to_additional_ui_effects_juncs_tables   显示「随击杀成长」标签
```

| 项 | 取值 |
|---|---|
| `intensity_type`（3） | `set`（直接取档位，法术精气之风 1/2 档）、`linear_multiplier`（0→max 线性放大，击杀/受伤叠层用）、`inverse_linear_multiplier`（源越大越弱） |
| `intensity_source`（26，**禁止新增**） | `kills_made`、`nearby_all_deaths`、`nearby_enemy_deaths`、`time_in_melee`、`damage_taken`、`mastery_of_elemental_winds`、`all_wom_spent`、`enemies_in_range`、`enemy_in_range_low_morale`、`harmony`、`units_in_range`…（全集读 `special_ability_intensity_sources_tables`） |
| `linear_multiplier` 公式 | 当前效果 ≈ 满强度效果 × (当前源值 / `max_amount`)；phase 里填**满强度值** |
| 每击杀 +1 武威 | `max_amount=100`、`intensity_source=kills_made`、`linear_multiplier`、phase 填 `stat_melee_attack add 100` |
| 档位 / 衰减 | `max_amount` 取 50/100/150/200/300/500；`decay_delay=-1` + `decay_duration=0` = 不衰减（最常用） |

- 击杀统计的是**兵模**，不是部队卡；「每次击杀**瞬间**回固定 % 生命」intensity 做不到，需战斗脚本轮询（见 `41-战斗脚本.md`）。

**验收**：`ability` 与 `unit_special_abilities.key` 同名；`intensity_source` 在 27 枚举内；UI 出现强度说明条。

## 4. 投射物 / 爆炸 / 破片 / 炮击 / 涡流

| 表 | 主键 | 关键字段 | 抄写对象 |
|---|---|---|---|
| `projectiles_tables`（v53） | `key` | `category` `shot_type` `effective_range` `muzzle_velocity` `spread` `damage` `ap_damage` `collision_radius` `projectile_display` `explosion_type` `contact_stat_effect` `is_spell` `ignition_amount` `is_magical` `expiry_range`（≥ `effective_range`） `spawned_vortex` `projectile_number` | 火球抄 `wh_main_spell_fire_fireball` |
| `projectiles_explosions_tables` | `key` | `detonation_radius` `detonation_damage` `detonation_damage_ap` `shrapnel` `explosion_particle_effect` `contact_phase_effect` `fuse_fixed_time`（常用 -1） `is_spell` | 原版同弹种爆炸 |
| `projectile_shrapnels_tables` | `key` | `projectile` `amount` `launch_type`（`hemisphere`） `sector_angle` | 原版破片配置 |
| `projectile_bombardments_tables`（v7） | `bombardment_key` | `arrival_window` `num_projectiles` `projectile_type` `radius_spread` `launch_source`（`above_activater`/`above_target`/`activaters_entities`/`launch_and_explode`/`off_map`） `launch_vfx` `randomise_launch` | 彗星/核弹类轰炸 |
| `battle_vortexs_tables`（v20，**拼写 vortexs**） | `vortex_key` | `change_max_angle`（0=直线/360=任意） `contact_effect` `damage` `damage_ap` `duration` `expansion_speed` `start_radius` `goal_radius` `movement_speed`（0=原地） `shape`（**不可空**：`circle`/`rectangle`/`arc`） `composite_scene` `is_spell` `affects_allies` `num_vortexes` | 烈焰风暴/风系/吐息 |

- 视觉资源（`projectile_display`、`explosion_particle_effect`、`composite_scene`、`launch_vfx`、音频）**引用原版 key**，只改数值与伤害。
- 涡流命中挂减益走 `contact_effect` → phase；爆炸命中走 `contact_phase_effect`。

**验收**：出口字段指向的 key 存在；`battle_vortexs.shape` 非空；`autoresolver_usage` 非空。

## 5. `spawn_is_*` 四种共现模式（原版全表扫描）

三个布尔只在带 `spawned_unit` 的能力上有意义。

| 模式 | `decoy` | `transformation` | `shares_health_and_fatigue` | 效果 | 抄写对象 |
|---|---|---|---|---|---|
| A 诱饵分身 | `true` | `false` | `false` | 本体仍在，额外生成诱饵（独立血条） | `wh2_dlc10_lord_abilities_mislead`（误导）、`wh3_dlc24_lord_item_deceiving_shadows`（虚影） |
| B 真变形 + 继承 | `false` | `true` | `true` | 本体被替换，继承血量比例与疲劳 | `wh3_main_lord_abilities_iron_dragon_{human,dragon}_form`（化龙诀）、`wh3_dlc24_lord_abilities_formless_horror`、`wh3_dlc27_unit_abilities_dread_maw_underground` |
| C 真变形 + 不继承 | `false` | `true` | `false` | 本体被替换但不共享血疲 | `wh2_dlc14_lord_abilities_tzarkan`（扎坎系，原版仅此） |
| D 普通召唤 | `false` | `false` | `false` | 额外刷兵，施法者不变 | 奈赫克/深渊召唤类 |

- `decoy` 与 `transformation` 原版**从不共用**；`shares_health_and_fatigue=true` 原版**只与** `transformation=true` 同现。
- 变形常配 `spawn_type=unit_position`、`affect_self=true`，可叠 `behaviour`（`changeling_transformation`/`go_underground`/`dig_yourself_out`）；普通召唤**不要**开 decoy/transform/share。

**验收**：三字段组合属于 A–D 之一；`spawned_unit` 指向的 `land_units` key 存在。
