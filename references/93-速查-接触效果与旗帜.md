## 1. 机制速查

挂载字段（5 处）：近战 `melee_weapons.contact_phase`｜投射 `projectiles.contact_stat_effect`｜攻击附魔 `special_ability_phases.imbue_contact`（该 phase 存续期间，攻击附带另一接触 phase）｜爆炸 `projectiles_explosions.contact_phase_effect`｜涡流 `battle_vortexs.contact_effect`（可为任意 phase）。

**`imbue_contact` 怎么用（攻击附魔）**

1. 建 phase A：`effect_type=positive`，`imbue_contact` 填接触 phase 的 key，`affects_allies=false`、`affects_enemies=true`、`is_hidden_in_ui=false`。
2. 建被动能力（`unit_special_abilities.passive=true`）→ `special_ability_to_special_ability_phase_junctions` 挂上 A。
3. 启用：`effects_tables` 自定义 effect + `effect_bonus_value_unit_ability_junctions`（值 `enable`）＋ bundle；或直接挂 `land_units_to_unit_abilites`。免疫用 `ignore_imbue_contact_effects_enemy` / `_ally`（见 `92-速查-属性与强度.md` §1.7）。

**与 `unit_attributes` 的区别**：接触效果是 **phase**，**允许**新建自定义接触 phase；`unit_attributes` **禁止**新增。

当前原版有 `special_ability_contact_phase_groups_tables`（`contact_phase_id` / `contact_phase_group_id`），用于接触效果分组，不是图标映射；上述 5 个字段仍是挂载入口（2026-10-08 核对）。

**自定义接触效果的图标与尺寸**：按 `31-技能图标.md` §4.1 分别配置兵种面板的 phase 同名 PNG 与效果名称的内嵌图标；复用原版图案也须核对各自目标槽位尺寸。
> ⚠️ `效果速查.md` §3 的 `wh_dlc06_unit_contact_shock`（震慑）在 `special_ability_phases_tables` 中**不存在** → 不可用；以 §3.1 的 78 条为准。

### 4.4 用法与重导

三个 junction 表结构均为 `flag<TAB>ability`（第 2 列是 `unit_special_abilities.key`），一行一条件；写自定义被动时**照抄原版同类被动的 flag**（例：不灭 = `morale_is_lower_than_half_of_base_morale`，与 `wh2_dlc15_banner_passive_da_immortulz` 一致）。重导：`Get-Content <表>\data__.tsv | Select-Object -Skip 2 | %{ ($_ -split "`t")[0] } | Sort-Object -Unique`。


## 5. `unit_set` 限定作用范围

`banners_permitted_unit_sets_tables`（`banner` / `unit_set`）决定这面旗**能挂给哪些部队**；`unit_set` 取值来自 `unit_sets_tables.key`（3,331 条），成员由 `unit_set_to_unit_junctions_tables` 定义（`unit_caste` / `unit_category` / `unit_class` / `unit_record` + `exclude` 排除）。

## 6. 做一面旗需要哪些表

**路径 A · 纯数值旗帜（6 张 + 文本）**：1 `banners_tables`（`banner`/`effect_bundle`）｜2 `banners_permitted_unit_sets_tables`（`banner`/`unit_set`）｜3 `effect_bundles_tables`｜4 `effect_bundles_to_effects_junctions_tables`（`effect_bundle_key`/`effect_key`/`effect_scope`/`value`/`advancement_stage`）｜5 `ancillaries_tables`｜6 loc：`ancillaries` + `effects` + `effect_bundles` 三组文本。

**路径 B · 带自定义被动（不灭 / 狂暴 / 接触类）再加 9 张**：

7. `effects_tables`（自定义 effect 行）｜8. `effect_bonus_value_unit_ability_junctions_tables`（`effect` / `enable` / 能力 key）｜9. `unit_abilities_tables`（`icon_name` / `type` / `source_type`）｜10. `unit_special_abilities_tables`（被动填 `passive=true`）｜11. `special_ability_phases_tables`（phase 本体）｜12. `special_ability_phase_attribute_effects_tables`（施加/移除 attribute）｜13. `special_ability_to_special_ability_phase_junctions_tables`（能力 → phase）｜14. `special_ability_to_auto_deactivate_flags_tables`（关闭条件，§4）｜15. UI 图标 + loc（`ui\battle ui\ability_icons\`、`unit_abilities` / `special_ability_phases` 文本）

> 数值类 effect 键与「启用链」对照（狂暴 / 重生 / 荣光冲锋 / 不灭意志等）见 `效果参考\效果速查.md` §2；接触类 effect 原版**没有**通用键，必须走路径 B 自定义（§1）。
