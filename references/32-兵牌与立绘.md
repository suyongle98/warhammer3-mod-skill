## 2. 兵牌 60×130：双槽位同步

### 2.1 两个槽位都要放（硬性）

- 同一张最终 60×130 图写入 `ui\units\icons\<名>.png` **和** `ui\portraits\units\no_culture\<名>.png`；两者是独立槽位，不是同一文件的引用。
- **验收**：两处 `magick identify` 均 60×130；`Get-FileHash` 两处一致。

> ⚠️ 坑：只改 `ui\units\icons` 就假定另一处会跟随 → 角色面板/横幅仍显示旧图或占位图。

### 2.2 文件名规则：`unit_card` 不必然等于 unit key

| 实例 | `unit_variants.unit_card` | 同表 `unit`（单位 key） | 实际文件 |
|---|---|---|---|
| 马鲁斯 | `def_malus_tzarkan_0` | `wh2_dlc14_def_cha_malus_darkblade_tzarkan_0` | `ui\units\icons\def_malus_tzarkan_0.png` |
| 袁博 | `placeholder` | `wh3_dlc24_cth_cha_yuan_bo_dragon` | 兵牌走占位；头像走 `portraits\units\no_culture\wh3_dlc24_cth_cha_yuan_bo_dragon.png` |

- **怎么做**：兵牌名取 `unit_card` 值；`portraits\units\` 槽位名取单位 key。两者不同时**各按各自规则命名**，不强行统一。
- **验收**：grep 该单位 `unit_variants` 行的 `unit_card`，确认 `ui\units\icons\<该值>.png` 存在。

### 2.3 尺寸与构图

| 项 | 要求 |
|---|---|
| 尺寸 | 严格 60×130，不拉伸填充 |
| 构图 | 头到胸肩**近景**；脸居中可读；头饰接近顶部但不切脸；底部只留领口/肩/少量胸甲 |
| 背景 | 先抠人物前景，再整体铺**单一纯色 RGB**；不得拼其他图的背景 |
| 禁止 | 文字、水印、UI 边框、重复人脸、无关角色；不得把全身像缩进竖条 |

### 2.4 验收

- [ ] 两处文件存在、均 60×130、哈希一致
- [ ] `eye_line_width >= 48px`，`eye_line_min_x<=3`、`eye_line_max_x>=56`（见 §6）
- [ ] 背景同一纯色 RGB；边缘无残留原背景/断层
- [ ] 缩略图下仍能认出角色

## 3. porthole 300×164 与 infopic 120×260

### 3.1 porthole：路径 / 命名 / 档名一致

- 路径 `ui\portraits\portholes\no_culture\<名>.png`，**300×164**，保留 alpha。
- **档名必须与 `ui\portraits\units\<文化>\<名>.png` 一致**（教程 21：两张图档名要一致）。
- DB 写**完整路径 + `.png`**（原版实测小写正斜杠）：`units_custom_battle_permissions_tables.general_portrait` = `ui/portraits/portholes/no_culture/skv_tretch_craventail_0.png`；`unit_general_details_tables.general_portrait` 同格式。
- `agent_uniforms_tables.campaign_porthole_filename` 写**裸名**（无路径无扩展名），例 `wh2_dlc09_skv_tretch_craventail`。

> ⚠️ 坑：`general_portrait` 写裸名或漏 `.png` → 头像不显示。
> ⚠️ 坑：MOD 写 `UI/Portraits/...` 大写、DB 写小写 → 能跑但易漏文件；同一 MOD 内保持一种写法。

### 3.2 文化目录：WH3 实测只有 `no_culture`（＋`dae_prince`）

原版 `ui\portraits\units\` 与 `ui\portraits\portholes\` 的子目录**各只有 `no_culture`、`dae_prince`**。

- 新建角色一律用 `no_culture`，并让 `general_portrait` 路径与之相符。
- **不要**照抄教程 21 的 WH2 势力代码目录（`ui>portraits>portholes>wh_main_emp_empire`）。
- 【待核对】特殊文化目录（如 `dae_prince`）以原版同文化文件所在目录为准。

### 3.3 `_mask1/_mask2/_mask3`（可选遮罩层）

- 原版 porthole 常带 `..._0_mask1.png` 等（换装/形态层）；`portrait_settings` 每条最多引用 3 张（RPFM 诊断项 `FileMask1/2/3NotFoundForVariant`）。卡捷琳原版**无** mask → 非必填。
- **怎么做**：复用原版 art set 时，若原版登记带 mask，要么一并覆盖同名 mask，要么确认新图不含该层。**验收**：该条引用的 `FileDiffuse`/`mask*` 路径都有实际文件。

### 3.4 infopic（120×260）

- 路径 `ui\units\infopics\<unit_card>.png`，120×260；可半身/近全身，但先看原版同槽位裁切。原版角色可**没有** infopic（实测 `infopics\def_malus_tzarkan_0.png` 不存在）→ 缺失不阻断；有则尺寸 120×260。

## 5. art set 与大地图 2D 头像完整性

## 6. 镜头标尺与裁切（可执行参数）

### 6.1 60×130 眼线标尺（唯一验收位）

| 参数 | 值 / 算法 |
|---|---|
| 参考图 | ≥3 张同类型原版或可靠 60×130 兵牌，**按原始尺寸并排比较**（放大预览只用于量像素）；眼线 = 双眼**瞳孔/眼球中心**所在行 |
| 目标眼线 | 每张记 `eye_percent_i = y_i / 130 × 100`，`target_y = round(均值)`（47/46/48 → `y=47`，36.15%） |
| 宽度测量 | 最终 60×130 的 `eye_y` 行建**只含脸＋头发**（排除头饰、肩、手、武器、裁切边）的前景掩码，`eye_line_width = max_x − min_x + 1` |
| 合格线 | **`>= 48px`**（画布宽 80%）；`<48` 直接否决重裁 |
| 常规贴边 | `eye_line_min_x <= 3` 且 `eye_line_max_x >= 56`（脸近左右边，但眼睛不被横切） |
| 脸中心 | 接近 `x=30` |
| 头饰 | 冠冕/角/羽翼允许顶部溢出画布，**永不计入眼线宽度** |

### 6.2 裁切公式（保持 6:13）

```
裁切框：60:130 = 6:13 → 宽度 W = H × 6 / 13（H = 源裁切高度）
缩放：  s = 130 / H = 60 / W
初始框：crop_x = face_center_x − 30 / s
        crop_y = source_eye_y − target_eye_y / s
```

- 只差 1-2 个目标像素时游戏内几乎看不出；若反馈「完全没改」，先并排对比 + 校验 SHA-256 确认文件变了，再做**明显但不过度**的位移。禁止把带大面积透明边或全身像直接缩成 60×130；先读 alpha 可见边界，定位脸/双眼/肩部再裁头肩近景。

### 6.3 300×164 porthole 构图

| 项 | 要求 |
|---|---|
| 构图 | 头像/半胸像；脸、头饰、身份特征清楚；不要远景全身 |
| 居中基准 | **双眼中点/脸部中心**居中到 `x≈150`（不是披风/武器的可见边界）；肩、手臂、既有武器可向两侧延伸 |
| 禁止 | 脸偏一边；用披风延伸误判为「居中」 |
| 通道 | 保留 alpha；四角透明 |

### 6.4 背景与抠图

- 先抠前景，**再整体丢弃原背景**铺单一纯色 RGB；禁止拼背景补片；无 alpha 源图要建前景掩码，保护面部高光、白色头饰/衣饰、头发边缘与抗锯齿过渡。
- 有设定图/原角色截图时，该图是脸型、发型、服装、配色、饰品的身份基准：**优先确定性裁切**，不做 AI 重绘。生成式稿只能当源素材，最终须本地确定性裁切/缩放。

### 6.5 验收数据格式（缺任一项视为未验证）

```
eye_y=47, eye_line_min_x=2, eye_line_max_x=57, eye_line_width=56px, headgear_excluded=true
canvas=60x130, background=#3A2E24, sha256_icons==sha256_portraits_units
```

不得用裁切框、头顶、纵向并集或头饰替代「眼线单行的真实头部宽度」。

## 7. 教程 21 的 bin / xml / selfie 流程 —— **【待核对】**（WH2 工具链）

### 7.3 在 WH3 怎么验证 / 怎么替代（按序做）

1. **先确认文件存在**：用随包 `inspect.js` 查当前 pack 的 `portrait_settings`，再按需要导出。
2. **优先「复用原版 art set」**：原版已有登记，只需把 PNG 放到原版同名路径覆盖（实测：工坊 `BeautifulVampires.pack` 只带 porthole PNG，**不带** bin）。
3. **只有新建 art set id 才写 bin**：用 **RPFM 5.0.6 Portrait Settings 编辑器**打开原版 `portrait_settings__.bin`，在原文件上追加后另存到 MOD 同名路径。MOD 内同名 bin 会**整体替换**原版（非逐条合并）【未验证：以加载顺序实测为准】→ 必须基于原版全量追加。
