## 0. 一页速览（先读这 6 条）

1. **图标一律 PNG + alpha**（`Format32bppArgb`，8 位 alpha）；DDS 只用于大图/图集/建筑图，不用于技能图标。
2. **自绘、复用或直接引用原版图标都须核对目标槽位尺寸**：先量原版同槽位文件；跨槽位复用须制作匹配尺寸的副本，不能只改名或改路径。尺寸偏差的具体显示后果须实测。
3. **"抠掉边缘" ≠ 去掉圆盘**：默认只把圆外方形区域变透明，圆环/圆盘/圆内场景全保留。
4. **目录名精确匹配**（含空格与大小写）：`ui\battle ui\ability_icons`、`ui\campaign ui\skills` 等。
5. 作者环境**没有** Python / `imagegen` 工具 → 抠图、缩放、校验一律用 `magick` + PowerShell `System.Drawing`。
6. 单 MOD 的实测值（如某 MOD 的 300×164）是**实例**，不是通用基准；通用值以本册 §1 表为准。

**分工**：本册讲**总规范与工具链**；技能图标的绘制细节、构图、程序化脚本见 `31-技能图标.md`；兵牌/立绘/porthole 见 `32-兵牌与立绘.md`。

## 2. 边缘抠图与透明画布（硬性规则 → 可勾选清单）

「抠掉边缘」的**默认含义**：只移除方形画布中**圆形图标本体之外**的区域。参考同类战斗能力图标：四角透明、圆盘完整。

**执行前必选一种模式**

| 模式 | 触发条件（用户原话） | 处理范围 |
|---|---|---|
| A 默认边缘抠图 | 「抠掉边缘」「抠图」「不要边缘背景」 | 只清圆外方形区域；圆环、圆盘、圆内暗底/场景、玻璃高光、中央图案**全保留** |
| B 中央主体抠图 | 明确说「只保留中央主体」「去掉圆环」「去掉整个圆形图标」「透明背景只留武器/人物」 | 移除圆盘本体，仅留中央主体及其不可分割的近距离效果 |

**A 模式清单**
- [ ] 成品为带 alpha 的 PNG（`Format32bppArgb` / 8-bit alpha）
- [ ] 四角与圆外区域 alpha = 0
- [ ] 圆盘内部按原视觉保留不透明或半透明像素
- [ ] 没有残留方形底色、没有硬切锯齿
- [ ] 圆环（金属/魔法外环）完整，未被啃掉
- [ ] 圆内暗底/场景背景完整，未被当成"边缘"删掉
- [ ] 圆外 1–2 像素可轻微渐隐，但不得把圆盘切成主体轮廓
- [ ] 做法：从**完整圆形源图**做确定性缩放 + 圆形 alpha 遮罩；**禁止**用色键或 AI 主体分离去圆盘

**B 模式清单**
- [ ] 主体居中缩放，四周保留约 **4–10%** 透明安全边距
- [ ] 主体外没有圆形外框、没有场景、没有大面积不透明底
- [ ] 边缘无绿边/黑晕/色键残边
- [ ] 做法：纯色键背景（`#00ff00`）+ `magick -fuzz ... -transparent` 或手工 alpha 遮罩

**共同验收**（三种底各看一次）
- [ ] 透明棋盘格底：四角 alpha=0，外框/场景不存在
- [ ] 黑底：边缘无黑晕、无灰边
- [ ] 浅色底：边缘无白边、无残留底色
- [ ] 原始尺寸 + 8 倍放大各看一次

> ⚠️ 坑：用色键去「边缘」→ 圆环和圆内背景一起被删，成品只剩一个孤立主体，与原版图标风格不符（正确做法见 A 模式清单）。
> ⚠️ 坑：只对整张方形图做 `-trim` → 圆盘被裁成外接矩形，四角不再透明。

## 3. 格式与压缩

### 3.1 PNG 与 DDS 的适用场景

| 格式 | 用于 | 不用于 |
|---|---|---|
| PNG（`Format32bppArgb`，8-bit alpha） | 技能图标、兵牌、portrait、porthole、infopic、UI 按钮、事件图 | 大面积图集/地形贴图（体积大） |
| DDS（压缩格式与通道按原始资源） | 建筑大图、单位分类大图、贴图、图集 | 技能图标（引擎按 PNG 取 `ability_icons`） |

- **技能图标一律 PNG**：`unit_abilities.icon_name` → `ui\battle ui\ability_icons\<icon_name>.png`。
- 事件图 `380×214` 实测为 **srgb（3 通道，无 alpha）**，不要给它加透明通道。
- DXT1/BC1 可含 1-bit Alpha；不按透明度统一转换角色贴图。格式、Alpha/Mip 与恢复见 `33-DDS贴图检查与恢复.md`（2026-10-08，未新做游戏实测）。

### 3.2 导出参数（ImageMagick 作者环境实测）

```powershell
$magick = 'magick'
# 统一成 32bpp ARGB PNG（color-type 6 = RGBA）
& $magick in.png -define png:color-type=6 out.png
# DXT5（带 alpha）
& $magick in.png -define dds:compression=dxt5 out.dds
# DXT1（无 alpha）
& $magick in.png -define dds:compression=dxt1 out.dds
# 先铺底再转 DXT1（避免黑边）
& $magick in.png -background black -alpha remove -define dds:compression=dxt1 out.dds
```

- **验收**：`& $magick identify -format "%f|%wx%h|%[channels]|%[compression]" out.dds` 输出含 `DXT5` 或 `DXT1`；PNG 输出 `srgba 4.0`。
- **mipmap 必要性**：技能图标/兵牌/UI 按钮**不需要** mipmap（游戏按 1:1 或整倍缩放显示，尺寸小，加 mip 只增体积且可能糊）；只有会被自由缩放的 3D 贴图/大图才需要。**作者环境未进游戏验证 mip 层数对 WH3 的实际影响 → 【未验证】**。

> ⚠️ 坑：给 38×38 / 59×59 图标加 mipmap → 缩到 19×19、9×9 时图案糊成一团，UI 里看不出主题（正确做法：图标不写 mipmap）。

### 3.3 像素格式与 DPI

- 像素格式：`Format32bppArgb`（= ImageMagick 的 `srgba 4.0`，8-bit alpha）。
- DPI：**96 DPI 即可**，DPI 不影响游戏渲染，只影响外部工具预览。
- **验收**：`magick identify -format "%[channels]|%[depth]"` → `srgba 4.0|8`。

### 5.3 程序化绘制（可复用骨架）

作者历史案例生成了 8 张 59×59 徽章，四角 Alpha 为 0；案例脚本不随包提供，下面保留可复用骨架。

```powershell
# 骨架：画布 → 抗锯齿 → 图元 → 保存 → 自检
$ErrorActionPreference = 'Stop'
Add-Type -AssemblyName System.Drawing

function New-Canvas([int]$w, [int]$h) {
  $bmp = New-Object System.Drawing.Bitmap($w, $h, [System.Drawing.Imaging.PixelFormat]::Format32bppArgb)
  $g = [System.Drawing.Graphics]::FromImage($bmp)
  $g.SmoothingMode    = [System.Drawing.Drawing2D.SmoothingMode]::AntiAlias
  $g.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
  return @($bmp, $g)
}

# 径向渐变圆盘：从外到内逐圈 FillEllipse（Graphics 无原生径向渐变）
function Draw-Disc($g, [float]$cx, [float]$cy, [float]$r, $outer, $inner) {
  for ($i = 22; $i -ge 1; $i--) {
    $f = $i / 22; $rr = $r * $f; $t = 1 - $f
    $col = [System.Drawing.Color]::FromArgb(255,
      [int]($outer.R + ($inner.R - $outer.R) * $t),
      [int]($outer.G + ($inner.G - $outer.G) * $t),
      [int]($outer.B + ($inner.B - $outer.B) * $t))
    $b = New-Object System.Drawing.SolidBrush($col)
    $g.FillEllipse($b, $cx - $rr, $cy - $rr, $rr * 2, $rr * 2); $b.Dispose()
  }
}

# 金属外环：三圈 DrawEllipse（暗外环 / 亮中环 / 内描边）
function Draw-Ring($g, [float]$cx, [float]$cy, [float]$r, $dark, $bright) {
  $p1 = New-Object System.Drawing.Pen($dark, 2.2)
  $g.DrawEllipse($p1, $cx - $r - 2, $cy - $r - 2, ($r + 2) * 2, ($r + 2) * 2); $p1.Dispose()
  $p2 = New-Object System.Drawing.Pen($bright, 3.0)
  $g.DrawEllipse($p2, $cx - $r, $cy - $r, $r * 2, $r * 2); $p2.Dispose()
}

# 符号：FillPolygon / FillPie / DrawBezier / DrawArc 组合
function Draw-Symbol($g, [float]$cx, [float]$cy, [float]$s, $color) {
  $b = New-Object System.Drawing.SolidBrush($color)
  $g.FillPolygon($b, @(
    [System.Drawing.PointF]::new($cx, $cy - $s),
    [System.Drawing.PointF]::new($cx + $s * 0.87, $cy + $s * 0.5),
    [System.Drawing.PointF]::new($cx - $s * 0.87, $cy + $s * 0.5)))
  $b.Dispose()
}

$c = New-Canvas 59 59; $bmp = $c[0]; $g = $c[1]
Draw-Disc $g 29.5 29.5 28.5 ([System.Drawing.Color]::FromArgb(255,18,6,6)) ([System.Drawing.Color]::FromArgb(255,198,22,14))
Draw-Ring $g 29.5 29.5 25.5 ([System.Drawing.Color]::FromArgb(255,74,52,16)) ([System.Drawing.Color]::FromArgb(255,148,116,48))
Draw-Symbol $g 29.5 29.5 12 ([System.Drawing.Color]::FromArgb(255,232,222,196))
$g.Dispose()
$out = '<WORKSPACE>\<MOD>\ui\battle ui\ability_icons\my_icon.png'
$bmp.Save($out, [System.Drawing.Imaging.ImageFormat]::Png); $bmp.Dispose()

# 自检：尺寸 + 四角 alpha
$img = [System.Drawing.Image]::FromFile($out)
"{0}x{1} cornerA=({2},{3},{4},{5})" -f $img.Width, $img.Height,
  $img.GetPixel(0,0).A, $img.GetPixel(58,0).A, $img.GetPixel(0,58).A, $img.GetPixel(58,58).A
$img.Dispose()
```

- **怎么做**：改 `Draw-*` 图元函数表达不同主题；画布尺寸按 §1 表；保存后立刻做四角 alpha 自检。
- **验收**：脚本输出 `59x59 cornerA=(0,0,0,0)`；`magick identify` 复核为 `srgba 4.0`。
- 更细的构图与主题规则见 `31-技能图标.md` §6。

> ⚠️ 坑：`$g` / `$bmp` 忘记 `Dispose()` → 大循环时句柄泄漏、文件被占用无法覆盖。

## 6. 批量尺寸/格式校验（命令实例）

```powershell

         Select-Object -ExpandProperty FullName
& $magick identify -format "%f|%wx%h`n" $files

# ④ 只挑出尺寸不对的（期望 59x59）
& $magick identify -format "%f|%wx%h`n" $files | Where-Object { $_ -notmatch '\|59x59$' }

# ⑤ 查四角 alpha（0 = 透明）
& $magick 'path\a.png' -format "A00=%[fx:p{0,0}.a] A58=%[fx:p{58,58}.a] Ac=%[fx:p{29,29}.a]`n" info:
```

- **验收**：③ 的输出行数 = 实际 PNG 数；④ 无输出；⑤ 四角 `A=0`、圆心 `A=1`。

## 7. 验收清单（尺寸 / 透明 / 边缘 / 命名 四查）

**查尺寸**
- [ ] 每张图用 `magick identify` 量过，尺寸 = §1 表或原版同槽位基准
- [ ] 直接引用原版图片也量过来源尺寸；跨槽位副本按目标尺寸校验
- [ ] 批量校验（§6 ④）无"尺寸不对"的残留
- [ ] 同一资源的多槽位（如兵牌同时进 `ui\units\icons` 与 `ui\portraits\units`）尺寸与内容一致

**查透明**
- [ ] 需要 alpha 的图 `channels` 含 `srgba`；事件图保持 `srgb`（无 alpha）
- [ ] 四角 alpha = 0（默认边缘抠图模式）
- [ ] 透明棋盘格/黑底/浅色底三种背景各看一次，无黑晕/白边/残底

**查边缘**
- [ ] 圆环、圆盘、圆内场景完整（A 模式）
- [ ] 无硬切锯齿、无 1 像素残留方框
- [ ] 主体未贴边挤满，占位接近参考图

**查命名**
- [ ] 文件名 = DB 字段值（逐字符，含大小写）
- [ ] 目录名 = §4.1 表（含 `battle ui`、`campaign ui` 中的空格）
- [ ] 自建资源带 MOD 专属前缀
- [ ] 报告写清了所有写回的文件全路径；**不打包 pack**

## 8. 已知缺口（需用户协助或后续实测）

| 缺口 | 影响 | 建议 |
