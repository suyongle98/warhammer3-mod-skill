# 02 · 环境与工具

> 本包不依赖作者的盘符、用户名、私人工作目录或 AI 客户端。Windows PowerShell 示例需 PowerShell 5.1+；Node 脚本建议当前受支持的 Node.js LTS，作者用 Node 24 验证。

## 1. 工具与职责

第一次使用的完整准备步骤见 [工具清单与准备](../工具清单与准备.md)。

| 工具 | 用途 | 是否必需 |
|---|---|---|
| RPFM（含 WH3 schema） | 查看/编辑 pack、导出 DB 和 loc | 制作 pack 时需要 |
| Node.js | 随包静态检查、版本审计、RPFM 辅助脚本 | 运行 .js 时需要，无 npm 依赖 |
| RPFM server | 随包 pack/extract/inspect 的接口 | 使用这三个脚本时需要；否则用 RPFM 界面 |
| Lua 5.1 的 luac | Lua 语法检查 | 写 Lua 时推荐，缺失须注明未检查 |
| The Asset Editor | 动画片段、元数据、骨骼/模型编辑 | 做相关资源时按需 |
| 随包 dds-inspect.js | 只读 DDS 头/SHA、格式与 Alpha 提示，不解码像素 | 运行时需要 Node.js |
| Ghidra + 兼容 JDK | 定向反编译、指令与调用链分析 | 仅原生分析任务按需，见 61 |
| Git / 文本编辑器 / 图像编辑器 | 版本管理、TSV/Lua 与图片 | 按需 |

下载与功能查看作者项目：[RPFM](https://github.com/Frodo45127/rpfm)、[The Asset Editor](https://github.com/donkeyProgramming/TheAssetEditor)、[Lua](https://www.lua.org/download.html)、[Node.js](https://nodejs.org/en/download)。RPFM server 脚本接口以 5.0.6 实测为基础；新版 API 变化需验证，不能仅有 RPFM 界面就当 server 已配置。

## 3. PowerShell 配置示例

下面通过输入取得实际路径；在同一个 PowerShell 窗口中使用。无需改系统永久环境变量。

```powershell
$SkillRoot = (Resolve-Path -LiteralPath (Read-Host '输入 warhammer-mod 解压目录')).Path
$Vanilla = (Resolve-Path -LiteralPath (Read-Host '输入当前原版导出根目录')).Path
$ModRoot = (Resolve-Path -LiteralPath (Read-Host '输入 MOD 源目录')).Path
$env:WH3_EXPORT_DIR = $Vanilla
node (Join-Path $SkillRoot 'tools/modcheck/check.js') $ModRoot --vanilla (Join-Path $Vanilla 'db')
node (Join-Path $SkillRoot 'scripts/audit-version.js') --source $Vanilla
```

需要 Lua 检查时设置 `$env:WH3_LUAC` 为已安装的 luac5.1 可执行文件完整路径；缺失时工具会明确提示未做 Lua 语法检查。静态检查需要原版 TSV，不能仅给 db.pack。

## 4. RPFM server 与 pack 工具

先在 RPFM 正确配置 WH3、游戏路径、schema 与依赖；server 需要来自支持该接口的 RPFM 发布包。手动启动 server，或将环境变量 `RPFM_SERVER` 设为实际 server 可执行文件路径。随包脚本默认连接本地 127.0.0.1:45127，未找到 server 时会报依赖缺失，不猜安装位置。

```powershell
$env:RPFM_SERVER = (Resolve-Path -LiteralPath (Read-Host '输入 rpfm_server 可执行文件路径')).Path
node (Join-Path $SkillRoot 'tools/rpfm-pack/inspect.js') (Read-Host '输入待查看 pack 完整路径')
```

打包、解包参数见 `tools/rpfm-pack/README.md`；游戏部署与公开发布按使用者授权执行。server/schema 版本变化导致接口不兼容时，用 RPFM 界面完成，保留错误供工具维护。

## 5. 编码与平台边界

中文文档 UTF-8；游戏 TSV/Lua 按原版和运行要求，通常 UTF-8 无 BOM。随包含中文 .ps1 为 UTF-8 with BOM 以支持 Windows PowerShell 5.1，.bat 是 ASCII 包装。dds-inspect.bat 使用 PATH 中的 node；没有时先配置 Node。Node 脚本使用参数路径，操作系统与第三方程序兼容性另外确认；本次工具核验在 Windows，未声称 macOS/Linux 全流程通过。
