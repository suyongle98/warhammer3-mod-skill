# 51 · 汉化审校与显示规则

> 适用：WH3 ｜ 事实截止：2026-10-22 ｜ 来源：`已完成mod\CN\巴托\@su_mlfsr` 第八版全量审校、原版中文库实测、`modcheck` 与 `rpfm-pack` 回读
> 可信度：A（标记计数与官方译名出处均可复核） ｜ 指纹：`[[b]]` 官方 430 处 / `『』` 9,040 处 / `「」` 7 处 / `“”` 0 处 / 星号强调案例 20 处
> 维护核验：2026-10-22；版本与来源范围见 `05-版本维护与核验.md`

## 0. 一页速览

1. 本册涉及的常见标记包括 `\\n`、`||`、`[[b]]`、`[[col:]]`、`[[img:]]`、`{{tr:}}`、`%+n`；**Markdown 星号会原样显示**。
2. mod 沿用原版 loc 键时，先查官方同名键的译名；英文未改写就直接用官方译文。
3. 交包前跑 `scripts\loc-audit.js`，各项检查没有 ERROR 再打包；WARN/INFO 逐条判读，静态检查不覆盖所有占位符语义或游戏显示。

## 1. 游戏内文本标记（实测）

| 标记 | 作用 | 官方用量 | 写错的后果 |
|---|---|---|---|
| `\\n` | 换行（字面三字符） | 11,689 | 物理换行会拆行，见 `50` §3 |
| 双竖线 | 条目内多条列表分隔（派系说明、加载提示） | 常见 | 用换行或逗号代替，列表挤成一段 |
| `[[b]]…[[/b]]` | 粗体 | 430 | 用 Markdown `*` 会原样显示 |
| `[[col:颜色]]…[[/col]]` | 文字着色 | 多 | 漏闭合会把整段染色 |
| `[[img:路径]][[/img]]` | 行内图标 | 多 | 路径写错显示空白 |
| `{{tr:key}}` | 引用另一条 loc | 多 | 目标 key 不存在时显示原文 |
| `%+n` / `%+n%` | 数值占位符 | 多 | 占位符被翻译或移位，数值不显示 |

- **依据**：官方库逐项计数；`[[b]]` 430 处、`『』` 9,040 处、`「」` 7 处、`“”` 0 处。
- **写法**：正文里的双竖线写作两条竖线，用于 `frontend_factions_localised_info_*`、`loading_screen_quotes_bulletpoints_*` 等条目，竖线之间不加空格。
- **怎么做**：按上表替换；占位符原样保留，数值结尾的条目不加句号。
- **验收**：`loc-audit.js` 的「标记配对」项无 ERROR；`[[b]]` 与 `[[/b]]` 数量相等。

## 2. 星号强调必须转 `[[b]]`

**结论**：原文用 `*浩瀚*` 这类 Markdown 强调时，游戏不解析，玩家会看到字面的星号；必须转成 `[[b]]浩瀚[[/b]]`，或直接去掉星号。

- **依据**：`@su_mlfsr` 第八版 20 处星号强调；官方库同类强调一律用 `[[b]]`，未见星号用法。
- **怎么做**：按键替换，正则 `\*([^*]{1,20})\*` → `[[b]]$1[[/b]]`；只对正文键执行，保留段落分隔符 `***`（如有）。
- **验收**：`grep -o '\*[^*]\{1,20\}\*'` 命中 0（`***` 除外）；`[[b]]` 与 `[[/b]]` 数量相等。

## 3. 同名键回退官方译名

**结论**：mod 覆盖原版 loc 键时，先查官方库同名键；mod 英文与官方英文相同（或只差标点）就直接用官方译文，mod 改写英文才重译。

- **依据**：`@su_mlfsr` 有 80 个键与原版同名，其中 74 条文本不同；`Gifted Beginnings`、`Power Familiar`、`Arcane Conduit`、`Earthing`、`Battle Pilgrims`、`Virtue of Empathy` 六处自译与官方冲突。
- **怎么做**：
  1. 取汉化 key，在 `游戏原文件\local_cn\text\localisation__.loc.tsv` 查同名 key。
  2. 有同名且英文未改写 → 用官方中文，不重译。
  3. 有同名但 mod 改写了英文 → 重译，但句中术语沿用官方（如 `Fleur de Lys` 统一「百合花」）。
  4. 无同名 → 走 `50` §4 术语查证。
- **验收**：所有与官方同名的键，译名要么与官方逐字相同，要么有明确的英文差异证明重译必要。

| 英文 | 官方译名 | 案例里的错误写法 |
|---|---|---|
| Fleur de Lys | 百合花 | 鸢尾花（同段又出现「百合」，自相矛盾） |
| Battle Pilgrims | 战斗朝圣者 | 圣杯朝圣者（与 Grail Pilgrims 混同） |
| Virtue / Vow of Empathy | 恤民美德 / 恤民之誓 | 共情美德 / 共情之誓 |
| Power Familiar | 魔力使魔 | 强力魔宠 |
| Gifted Beginnings | 天赋英才 | 天赋初显 |
| Arcane Conduit | 奥术导体 | 奥术导管 |
| Earthing | 缚风大地 | 接地 |
| Couronne | 哥隆尼 | 库隆尼 |

## 4. 批量审校脚本

**结论**：交包前跑一次 `scripts\loc-audit.js`，用参考英文包与官方库做下列静态检查。没有扫描到 loc 或参数/环境错误时退出码为 2，不算审校成功。

```bat
node "<SKILL>\scripts\loc-audit.js" "<MOD目录>" ^
  --ref "<英文参考解包目录>" ^
  --official "<VANILLA>\local_cn\text\localisation__.loc.tsv"
```

| 检查项 | 抓什么 | 判读 |
|---|---|---|
| 文件结构 | 首行 `key\ttext\ttooltip`、第 2 行 `#Loc`、列数、BOM、末尾换行 | ERROR |
| 键覆盖 | 与参考包对比缺键/多键 | 缺键 ERROR；多键 INFO |
| 段落数 | `\\n\\n` 数量与原文是否一致 | WARN 后人工看 |
| 星号残留 | `*强调*` | WARN |
| 标记配对 | `[[b]]`/`[[/b]]`、`[[col`/`[[/col]]` 数量 | ERROR |
| 英文残留 | 长度 ≥ 4 的英文词（排除标记与白名单） | WARN |
| 中文空格 | 汉字之间的空格 | WARN |
| 半角标点 | 中文语境里的 `, ; : ! ?` | WARN |
| 数字不一致 | 原文与译文数字集合不同（`%+n` 除外） | WARN |
| 官方同名 | 与官方同键相似度 ≥ 0.6 且文本不同 | INFO 提示回退 |
| 多文件同键 | 主体与外观兼容文件同键不同值 | ERROR |
