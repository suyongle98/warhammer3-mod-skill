## 0. 本册边界

| 本册写 | 本册不写（去哪） |
|---|---|
| 怎么找表、怎么读表头、怎么查主键类型 | 各业务域**字段怎么填**（`11`-`15` 各域册） |
| 1,603 张表的域导航 + 反向索引（想做什么 → 查哪张表） | 具体 key 清单与数值（现查 `data__.tsv`，不背数据） |

## 1. 查表三步法（所有 DB 工作的起点）

**结论**：任何字段名、key、数值都不许凭记忆写；一律走三步。

| 步 | 做什么 | 命令 / 位置 | 验收 |
|---|---|---|---|
| ① 找表目录 | 在 `<VANILLA>\db\` 找 `<表名>_tables` | `Get-ChildItem -Path "<VANILLA>\db" -Directory -Filter "*<关键词>*"` | 目录存在，且是复数 `_tables` |
| ② 读表头 | 读该目录下 `data__.tsv` **第 1 行**（列名）与**第 2 行**（`#表名;版本;路径`） | `Get-Content -LiteralPath "...\db\<表名>\data__.tsv" -TotalCount 2 -Encoding UTF8` | 列名顺序与版本号都拿到 |
| ③ 抄基准 | 找一条**原版同类**数据行，复制后改值 | `Select-String -LiteralPath "...\data__.tsv" -Pattern "^<原版key>\t"` | 新行结构与基准逐列一致 |

> ⚠️ 坑：直接照教程/旧技能里的列名填 TSV → 列名或列序已变，RPFM 导入报错或数据错位（`60-日志与崩溃排查.md` §3 类别 2）。

**列数校验（导入前必做）**：数据行按制表符拆分的段数必须等于表头列数。
```powershell
((Get-Content -LiteralPath "...\db\<表名>\data__.tsv" -TotalCount 1 -Encoding UTF8) -split "`t").Count
```

**按任务查，不按表名查。** `→` 表示引用关系。

## 5. 主键类型与上限（**别凭记忆**）

**结论**：数值主键是否溢出，取决于该列在 `schema_wh3.ron` 里的 `field_type`；**不同表不一样**，必须逐表查。

| 字段类型 | 范围 | 处置 |
|---|---|---|
| `StringU8` / `OptionalStringU8` | 任意字符串 | 无溢出问题，注意唯一性 |
| `I32` | −2,147,483,648 ~ 2,147,483,647 | **超上限 → 该行静默不加载** |
| `I64` | ±9.2×10¹⁸ | 几乎不会溢出 |
| `F32` | 单精度浮点 | 数值列，非主键场景 |

**实测对照（纠正旧说法）**：

| 表 | 主键字段 | schema 类型 |
|---|---|---|
| `building_units_allowed_tables` | `key` | **`I32`**（真会溢出） |
| `cdir_events_incident_payloads_tables` / `_dilemma_` / `_mission_` | `id` | **`I64`** |
| `pooled_resource_factor_junctions_tables` | `unique_id` | `StringU8`（**不是数字**） |
| `missions_tables` / `rituals_tables` / `ritual_payloads_tables` | `key` | `StringU8` |

> ⚠️ 坑：旧技能正文断言 `cdir_events_incident_payloads_tables.id` 是 `I32` —— schema 实测为 **`I64`**。**结论仍成立**（别用 90 亿级数值，那是坏习惯），但**理由要写对**；其他表是否 `I32` 必须现查 schema。

## 6. RPFM schema 用法（历史案例未装 Python）

| 项 | 历史案例事实 |
|---|---|
| schema 文件 | `<RPFM_CONFIG>\schemas\schema_wh3.ron`（10,769,707 字节，`version: 5`，本次文件字节指纹见 `assets/version-baseline.json`） |
| 同目录 | 另有 `schema_wh2.ron`、`schema_3k.ron` 等 14 份；WH3 只认 `schema_wh3.ron` |
| 无 Python | 旧技能的 Python 查询脚本**跑不了**，改用下面的 PowerShell 或 RPFM GUI |

**查主键字段类型（PowerShell，替换 `$t`）**：

```powershell
$schema = "<RPFM_CONFIG>\schemas\schema_wh3.ron"
$t = "building_units_allowed_tables"
$lines = [System.IO.File]::ReadAllLines($schema, [System.Text.Encoding]::UTF8)
$start = ($lines | Select-String -SimpleMatch "`"$t`": [" | Select-Object -First 1).LineNumber - 1
$end = $start + 1
while ($end -lt $lines.Count -and $lines[$end] -notmatch '^        "[^"]+": \[') { $end++ }
$chunk = ($lines[$start..($end-1)] -join "`n")
[regex]::Matches($chunk, 'name: "([^"]+)",\s*\n\s*field_type: (\w+),\s*\n\s*is_key: (true|false)') |
  Where-Object { $_.Groups[3].Value -eq 'true' } | ForEach-Object { "$($_.Groups[1].Value) : $($_.Groups[2].Value)" }
```

**RPFM GUI**：`<RPFM_UI>` → Game Select 选 **Warhammer 3** → 打开 `db/<表名>_tables/data__.tsv`，列头与类型直接可见。schema 更新走 `About > Check Schema Updates`；更新失败先核对游戏路径/网络并备份现有 schema。

> ⚠️ 坑：`rpfm_server.exe` 是 GUI 后端（监听 `127.0.0.1:45127`），**不是**命令行工具，`--help` 不返回用法。需要命令行能力时用上面的 PowerShell。现成 `rpfm-pack` 与直连客户端已经封装该接口；打包/解包/查看直接复用，不挂载全量 MCP。

## 7. 命名规律与引擎内部表

### 7.1 目录与文件

| 规律 | 示例 | 说明 |
|---|---|---|
| 表目录 = 表名（复数 `_tables`） | `effects_tables` | 与 schema 里的表名完全一致 |
| 数据文件 = `data__.tsv` | `db\effects_tables\data__.tsv` | 原版全量数据 |
| 第 1 行 = 列名（制表符分隔） | `effect	icon	priority	…` | 顺序即列序 |
| 第 2 行 = `#<表名>;<版本>;<路径>` | `#effects_tables;0;db/effects_tables/data__` | 版本 = schema 的 `version` |
| MOD 增量文件 | `!前缀_表名.tsv` | 语义见 `04-通用纪律与验收.md` §1.2 |

**本地化键 = 表前缀 + 完整键名**：如 `effect_bundles` 的 `localised_title` 列 → 键 `effect_bundles_localised_title_<key>`；`character_skills` 的 `localised_name` → `character_skills_localised_name_<skill_key>`。详见 `50-本地化与翻译.md`。

### 7.2 引擎内部表（MOD 不该动）

`cai_*` 177（战役 AI 决策）、`audio_*` 86、`frontend_*` 7、`loading_screen*` 7、`_kv_*` 12 —— **合计 289 张，占全库 19%**。改这些会崩或让 AI 变傻；需要时只读不写。确需改动时，在自己的 MOD 目录做增量覆盖并单独备份。

## 8. 域计数与表版本重生成

```powershell

$dirs = Get-ChildItem -Path $db -Directory | Select-Object -ExpandProperty Name
"total=$($dirs.Count)"   # 1,603
"internal=$(($dirs | Where-Object { $_ -match '^(cai_|audio_|loading_screen|frontend_|_kv_)' }).Count)"  # 289
# 各域前缀计数（§2 表格的数从这来）
$dirs | Group-Object { ($_ -split '_')[0] } | Sort-Object Count -Descending |
  Select-Object -First 25 Name, Count | Format-Table -AutoSize
# 单表版本与列数（§4 的数从这来）
$t = "unit_special_abilities_tables"
$h = Get-Content -LiteralPath "$db\$t\data__.tsv" -TotalCount 2 -Encoding UTF8
"cols=$(($h[0] -split "`t").Count)"; $h[1]
```
