## 2. attribute 的挂载位置（MOD 用）

| 用途 | 表 / 手段 |
|---|---|
| 单位自带属性 | `land_units.attribute_group` → `unit_attributes_groups_tables` → `unit_attributes_to_groups_junctions_tables`（`attribute` / `attribute_group`） |
| 技能相位施加 / 移除 | `special_ability_phase_attribute_effects_tables`（`attribute` / `phase` / `attribute_type` = `positive` 施加、`negative` 移除） |
| 战役效果永久启用 | `effect_bonus_value_unit_attribute_junctions_tables`（列序 `bonus_value_id` / `effect` / `unit_attribute`，值填 `enable`）；按集合用 `effect_bonus_value_unit_set_unit_attribute_junctions_tables` |
| 单位集合直接挂 | `unit_set_unit_attribute_junctions_tables`（`key` / `unit_attribute` / `unit_set`） |
| 战斗上下文条件启用 | `battle_context_unit_attribute_junctions_tables`（`key` / `battle_context` / `unit_attribute`） |
| 脚本检测 | `has_attribute("key")`（战斗单位接口） |

**组合关系**：`skink`↔`kroxigor`（灵蜥获恐惧／巨蜥获武器威力）；`peasant`↔`knight`（农民获领导力／骑士无视农民溃逃）；`yin`/`yang`（邻近异性触发宁和）；`charge_defense*` vs `ogre_charge*`（齐整抵消冲锋／食人魔仅部分损失）；`revealed` 使 `hide_forest`/`stalk`/`unspottable` 失效；不稳定五族 = 不溃逃 + 士气伤血 +（多数）心理免疫。

## 3. 能力强度（intensity）

### 3.1 三张表的关系

- `special_ability_intensity_settings_tables`（559 行）：某能力**如何积攒强度** —— 源、类型、上下限、衰减
- `special_ability_intensity_sources_tables`（27 条）：全部合法 `intensity_source`，**禁止新增**
- `special_ability_intensity_types_tables`：全部合法 `intensity_type`（3 种）

强度改变的是该能力所挂 **phase 的数值效果**（`special_ability_phase_stat_effects` 的 add/mult、`heal_amount` 等），**不是**战役 effect bundle。

链路：`unit_abilities` / `unit_special_abilities` → `special_ability_to_special_ability_phase_junctions`（效果本体）＋ `special_ability_intensity_settings`（随战斗状态放大/缩小）。

UI 补充说明常挂在 `unit_abilities_to_additional_ui_effects_juncs` → `unit_abilities_additional_ui_effects`（如击杀类 `wh3_dlc26_ability_intensity_kills_50/100/150/200/300/500`）。

### 3.2 `special_ability_intensity_settings` 字段

| 字段 | 含义 |
|---|---|
| `ability` | → 能力 key（通常与 `unit_special_abilities.key` 同名） |
| `default_amount` | 默认强度（开战 / 无源数据时的基准） |
| `max_amount` | 强度上限（`linear_multiplier` 下满强度对应 phase 表里的完整数值） |
| `intensity_source` | → `special_ability_intensity_sources.source_type` |
| `intensity_type` | → `special_ability_intensity_types.type` |
| `intensity_decay_delay` | 停止积攒后多久开始衰减；`-1` = 通常不衰减 |
| `intensity_decay_duration` | 衰减到 0 所需时间；`0` + delay `-1` = 常见「不衰减」组合 |
| `reset_intensity_in_reinforcement_pool` | 在增援池中是否重置强度 |

### 3.3 `intensity_type`（仅 3 种）

| type | 作用 | 原版用量 |
|---|---|---|
| `set` | 直接采用强度源给出的档位/数值（如精气之风 1/2 档） | 437 |
| `linear_multiplier` | 从 0 → `max_amount` **线性**放大 phase 效果 | 119 |
| `inverse_linear_multiplier` | **反向**线性（源越大，效果越弱） | 3 |

### 3.5 `linear_multiplier` 经验公式

- phase 表里填的是「**满强度**」效果。
- 当前效果 ≈ `满强度效果 × (当前源值 / max_amount)`（封顶于 `max_amount`）。
- 例：`max_amount=200`，phase 中 `stat_melee_damage_base = 200 add` → 约等于每击杀 **+1 普伤**（到 200 封顶）。

### 3.6 配方：每击杀叠属性（本场战斗）

| 项 | 建议值 |
|---|---|
| `intensity_source` | `kills_made` |
| `intensity_type` | `linear_multiplier` |
| `max_amount` | 50 / 100 / 150 / 200 / 300 / 500（对齐原版 UI 文案档） |
| `default_amount` | 通常 `0` |
| 衰减 | `intensity_decay_delay=-1`、`intensity_decay_duration=0` |
| phase 数值 | 填**满强度**值；要「每杀 +1 武威」则 `add` 值 = `max_amount` |

> ⚠️ 坑：击杀统计的是**兵模**，不是整支部队卡。
> ⚠️ 坑：想做「**每次击杀瞬间**回固定 % 生命」——强度系统**做不到精确**；需战斗脚本轮询 `number_of_enemies_killed()` + `heal_hitpoints_unary`。持续回血变快则可以用 `heal_amount` + `kills_made`（原版「饥饿如斯」）。
> ⚠️ 坑：不要把 UI 文案里的「附近施法」等描述当成新 source key —— 以 27 个枚举为准。
> ⚠️ 坑：`set` 与 `linear_multiplier` 语义不同；法术精气之风用 `set`，击杀/受伤叠层用 `linear_multiplier`。
